# CYB-001 — Malware / Ransomware Event

## Rule Information

Rule ID: CYB-001  
Domain: Cyber Resilience  
Category: Malware / Ransomware  
Status: Active  
Version: 1.0  
Repository: Sextant Rule Library  

## Purpose

Evaluate system resilience under malware or ransomware conditions and assess potential impacts across data integrity, system availability, operational continuity, and interconnected domains.

## Scenario

A malware or ransomware event compromises one or more systems through malicious software execution, infected files, compromised endpoints, or trusted system pathways. The event may cause data encryption, system degradation, service disruption, or loss of operational availability.

The scenario evaluates:

- Malware detection effectiveness
- Endpoint containment capability
- System isolation readiness
- Data integrity
- Backup and recovery readiness
- Service continuity

## Primary Indicators

- Malware detection alerts
- Abnormal endpoint behaviour
- Unauthorized process execution
- File encryption or modification events
- Rapid system performance degradation
- Suspicious network communication
- Backup integrity warnings

## Risk Levels

### GREEN

No malware activity detected.

Systems operate normally and security controls are functioning as expected.

No contingency actions required.

### YELLOW

Early indicators of suspicious malware activity.

Monitor:

- Unusual endpoint behaviour
- Suspicious processes
- Abnormal file activity
- Security alerts

Action:

Increase monitoring, validate endpoint security controls, and prepare containment procedures.

### ORANGE

Confirmed malware or ransomware activity affecting limited systems.

Indicators:

- Malware detected on endpoints
- Suspicious file encryption or modification
- Partial system degradation
- Potential lateral propagation

Potential Cascade:

Malware Detection  
↓  
Endpoint Compromise  
↓  
System Degradation  
↓  
Service Disruption

Action:

Isolate affected systems, contain the incident, protect critical services, and validate backup availability.
